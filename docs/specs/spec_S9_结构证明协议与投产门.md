## D-1 恒等式七关证明协议

- **背景**：探索发现大量数据层恒等式（IT=NonAI+AI、功率平衡等），
  但"发现"不等于"结论"——须排除数据异常/建模失误/模型局限（三关纪律·口径干净）
- **决策**：每条恒等式通过 7 关才入册为【实证】：
  1. 全时域逐点残差统计（mean/max/p99/std）
  2. 四段成立（train 0-2351 / cal 2352-2375 / frozen 2376-2399 / closure 2400-2406）
  3. 数值精度（相对残差 <1e-6，排除浮点巧合）
  4. 构造性交叉验证（独立数据源重建一侧；表内恒等式为附加证据，生成口径恒等式必过）
  5. 反证（残差与全 21 列特征相关 <0.1；相对量级 <1e-6 时相关无意义直接通过）
  6. 敏感性（输入 ±0.1% 扰动，残差按同阶线性传导 = 代数关系非巧合）
  7. 结论分级【实证】/【推断】/【存疑】+ 入 CONSTITUTION 恒等式集
- **备选**：单次残差验证（被否：无法区分"恒等"与"舍入巧合"）；
  全关必过含构造性（被否：表内恒等式与生成口径恒等式的证据要求不同）
- **验证**：I1-I7/I10/I13 九条六区实证（残差 1e-7~1e-9）；
  I11 存疑→追查破案（分数 Overlap）；I8/I9 明确"关系检验非恒等式"
- **判定器教训**：c5 反证关初版用绝对量级门，1e-4 舍入噪声误伤 1e-9 恒等
  （#37）→ 改相对量级门（rel<1e-6 直接 pass）

## D-2 投产门机制

- **背景**：探索产出大量结构发现，但未证明的发现不得进入生产代码
  （用户："先确定了再建模，不要把不确定的东西投产"）
- **决策**：三态管理——【已证明】可投产并登记 CONSTITUTION；
  【待验证】仅作论文素材/探索记录，禁止出现在任何 step 脚本；
  【存疑】按"数据异常/建模失误/模型局限"三类归因 → 进错误总账
- **备选**：发现即投产（被否：I11 式口径差异会污染评估链）
- **验证**：L1 依赖 I1 证明门（E/F 冻结段 22.9→4.6）；L5 依赖 T1 证明门
  （W 公式残差 0.0043MW 断言入 step3.1）；L10 不依赖新发现直接修评估层

## D-3 L1 NonAI 恒等式分层（I1 投产）

- **背景**：NonAI 冻结段 E/F MAPE 13-16%（树类），被诊断为 AI 镜像污染
- **实证**：I1 IT=NonAI+AI 逐点成立（rel 6e-10）+ IT_Load 稳定模板（漂移<1%）
- **决策**：NonAÎ = IT_Load 模板 − AI 实际；**双口径声明**——
  CV 内 S1 用验证段 AI = oracle 口径（上限参考）；冻结段 S1 =
  部署口径（说明2：2376-2399 调度输入=实际任务）
- **理论恒等**：S2（IT_Load 模板 − AI 均值模板）≡ S0（直接模板）——
  均值线性算子可交换（I1 + 线性性），纯预测口径分层无增益；
  增益全部来自"AI 实际值"这一额外信息
- **备选**：直接模板（维持 22.9%）；滚动重估（L4 裁决：非单调序列无增益）
- **验证**：冻结段全区域改善 37-80%（A 3.79→1.78 / E 22.94→4.56 / F 19.82→6.29）；
  tests 守卫：S1< S0 全区域 + S2≡S0（<0.02）

## D-4 L10 评估链修复

- **背景**：点模型 cov≈1.0 度量假象（±1.28σ 全序列合成区间）+ seg_price_level
  目标泄露（段均电价用全 2407h 含测试段）
- **决策**：点模型 q=None 不产出 cov/width/pinball（任务侧裁决=覆盖率/pinball，
  点模型明确拒绝）；seg_price_level 改训练段 0-2351 口径
- **备选**：保留合成区间并声明（被否：cov≈1.0 会被误读为模型超神）
- **验证**：类选结论不变（任务 0/144 拒、能源 126/192 过、Jaccard 0.797）——
  修复前结论已稳健，修复后口径干净

## D-5 可复现性纪律

- **背景**：deep 权重初始化/TabPFN 内部 RNG 无 seed → deep_lstm 通过数 9↔10
  边界翻转（#42）；竞技榜运行间不可复现
- **决策**：CV 每折、融合 OOF 每折、全段 fit 前一律 `seed_everything(SEED)`
- **验证**：同序列两次运行 max diff = 0（逐位一致）
