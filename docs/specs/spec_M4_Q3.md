## 问题定义（忠实题面）

Q3：给定任务调度与逐时负荷（说明4：D=(Baseline_AI_IT_Load+NonAI_IT_Load)×PUE），
只优化储能充放电/购售电/新能源分配；设计储能充放电策略；分析对**运行成本、
碳排放、区域峰值净购电功率、负荷波动程度**四指标的影响（vs 附件基准）。
波动口径自定（题目未给）→ **双指标并列**：净购电 std + 最大爬坡 max|Δ(G−S)|
（用户确认；实证：D 区成本最优解 std −37% 但爬坡 +81%，二者行为相反）。

## D-1 评估器口径（step3.2，Q3 对照锚点）

- **背景**：Q3 影响分析需要独立于 Q1/Q2 的四指标评估器（Q1 评估器是
  cost/carbon/nu/viol，无峰值与波动维度）
- **决策**（附件1 唯一口径）：
  - Cost = Σ(price·G − sellp·S)（万元）；Carbon = Σ(carb·G)（吨）
  - P_peak = max_t(G−S)（区域峰值净购电）
  - Vol_std = std(G−S)；Ramp_max = max|Δ(G−S)|（波动双指标并列）
  - NU = 1 − Q/W（I5 恒等式）为**伴随指标**（题目四指标不含，但说明3 要求
    统一口径重算；用于 32.9%→75-85% 叙事对照）
  - 时域 0-2406 全 2407h（说明6：2400-2405 结清计入结算；2406 仅终态）
- **备选**：Q1 评估器扩展（被否：viol/超容概念不适用 Q3，需独立评估器）
- **验证**：基准四指标与手算锚点一致（rel<1e-9，测试守卫）；
  LP 四指标与 lp_all_regions.json 交叉一致；平衡式残差<1e-6（I2 守卫）

## D-2 优化题验收体系（"高准确率"定义，严禁预测指标错配）

- **背景**：agent-ml model-evaluation 指标表对优化题无对应行；把 Q1 预测框架
  （CV/MAPE/覆盖率）套到 Q3 = 指标错配（math-methods 分层指标教训）
- **决策**：Q3 验收 = 优化题三件套：
  | 层 | 指标 | 门槛 |
  |---|---|---|
  | LP 解 | 约束残差（平衡式/SOC/弃电下界） | 相对残差 <1e-6（#37 相对量级门） |
  | 四指标核算 | 与手算锚点逐区一致 | rel <1e-9 |
  | 最优性 | ε-约束 δ 收紧→目标单调不减 | 断言守卫 |
  | 权衡面 | ε-约束 ∩ 加权和 双方法收敛 | 目标差距 <0.1% |
  | 规则层 | 规则模拟损失（按规则重调度→重算四指标） | 成本差距 <0.1%（探索后定标声明） |
  | MPC | 每窗口可行 + open-loop 对照 | 100% 可行 |
  | Sobol | 估计器解析验证（V2） | 误差 <1% |
  | 可复现 | 两次运行逐位一致 | max diff = 0（#42 纪律） |
- **防自我实现预言**：探索参数（δ/k/N）与验收锚点分离声明——改进率一律
  对照固定基准（D-1 锚点）计算，不因探索参数选择而改变

## D-3 多目标结构（step3.3）：凸性前提 + 双方法裁决 + 2D 投影

- **背景**：cost-only LP 实证使 D 区爬坡恶化 +81% → 四指标存在真实权衡，
  多目标变体是必需项（非加分项）；先前教训：review_A0 #7（单方法裁决被
  清算）、sum_8 #7（4D-HV 高维稀疏弃用）
- **决策**：
  - **H7 凸性假设显式化**：cost 线性、peak=max(线性) 凸、ramp=max(线性) 凸
    → 多目标凸 → ε-约束法（Chankong-Haimes）前沿完备性成立；加权和
    （正权重）得 Pareto 点——这是"不用 NSGA"的数理依据
  - **显式决策记录**：Q3 不用 NSGA-II/III（连续变量+凸结构+LP 精确性；
    标量化方法是数学正确选择；Q2 用 NSGA 因离散任务批+黑箱评估器——结构不同）
  - **双方法裁决协议**：前沿点须 ε-约束法 ∩ 加权和法收敛（目标差距 <0.1%）
    才入册；单方法出现的点标注"方法依赖"（B6 五方法裁决精神移植）
  - **2D 成对投影裁决**：三目标（cost×peak×ramp）用成对 2D 前沿裁决 +
    3D 散点仅展示；聚合指标（加权 HV 等）禁用（4D-HV 教训）
  - 峰值线性化 G−S≤P̄（T 条线性约束）；爬坡线性化 |Δ(G−S)|≤R̄（2(T−1) 条）；
    std 直接控制为 QP/SOCP（14442 变量稠密风险）→ 探索 MAD/Chebyshev/ramp
    代理（均有 LP 表达 + 与 std 的理论界），代理-真 std 相关实证后声明
- **验证**：单调性守卫；双方法收敛统计；代理相关实证表

## D-5 MPC 口径（step3.5）：自造场景声明 + open-loop 对照

- **背景**：数据 W 为确定性模板（T1 精确公式）→ 波动为自造
- **决策**：场景=W 公式模板×AR(1) 扰动（σ∈{10%,20%,30%}）×K-means 缩减
  8-16（质量<5% 已验证 0.0%）；24h 滚动 MPC；**对照纯度**：同一场景集下
  open-loop（均值场景一次求解）vs closed-loop（滚动反馈）→ 差值=反馈价值
- **备选**：直接报 MPC 结果不对比（被否：对照纯度三关不过，无法证明
  滚动价值）
- **验证**：窗口效应基线对照（D 0.06%/E 2.17% 已有）；每窗口可行断言；
  诚实声明"扰动自造，MPC 价值=方法论演示+鲁棒对比"

## D-6 Sobol 自实现（step3.6）：估计器验证门 + 参数化声明

- **背景**：环境无 SALib；用户批准自实现（scipy.stats.qmc.Sobol + Saltelli
  估计器，~30 行）
- **决策**：
  - **V2 估计器验证门**（恒等式 7 关"构造性交叉验证"精神）：先解析测试
    ①线性模型 Y=Σajθj：S1j=STj=aj²Var(θj)/Var(Y)（误差<1%）②加法模型
    ST=S1 ③交互模型 Y=θ1θ2：ST>S1——通过后才接 LP 黑盒
  - 参数 θ=(Cap, ηc, ηd, 价格水平, SellLimit, σ)；**价格参数化保持
    t=1245 变点结构**（等比缩放，非平移）
  - Y=(cost, carbon, P_peak, Vol_std, Ramp_max)——波动双指标分别归因
  - 采样预算标定先行（LP 0.1s/区 × N）；N=256-512，代表区 D/E/A
- **验证**：S1∈[0,1]、ST≥S1、ΣS1≤1；估计器解析测试<1%；seed 固定两次
  运行 max diff=0

## 核心公式

```
(3.1) G + W + Pd = D + Pc + S + Q                    ← 附件1+I2（W 全进）
(3.2) SOC(t)=SOC(t−1)+ηc·Pc(t)−Pd(t)/ηd             ← 附件1+I6（分区效率）
(3.3) Q ≥ W − min(W, c_h(h)·D) − Pc − S             ← R1 模板能力（弃电下界）
(3.4) SOC(2406) ≥ InitialSOC                        ← 防终点套利
(3.5) Cost=Σλ·G−Σλs·S；CE=Σc·G；P_peak=max(G−S)；
      Vol_std=std(G−S)；Ramp_max=max|Δ(G−S)|
(3.6) G−S ≤ P̄ ∀t                                    ← 峰值 ε-约束（线性）
(3.7) |Δ(G−S)| ≤ R̄ ∀t                               ← 爬坡 ε-约束（线性）
(3.8) MPC: min Σ_ω p_ω·Cost_ω s.t. ∀ω(3.1-3.4)；仅执行首时段
(3.9) Sobol: S1_j=Var(E[Y|θ_j])/Var(Y)；ST_j=1−Var(E[Y|θ_~j])/Var(Y)
```
