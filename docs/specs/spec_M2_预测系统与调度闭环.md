# spec_M2 — Q1 预测系统与调度闭环架构决策

> 决策记录：每项含备选方案与否决理由（2023C 惯例）。

## D-1 评估器消纳口径
- **决策**：U = min(W, c_r·D)，c_r 从题目基线校准（区域系数 0.12-0.56，收尾段 1.0）
- **备选**：全覆盖消纳 U=min(W,D)（成本崩为负值，与题目数据不自洽）
- **理由**：题目基线列间功率平衡残差 ~110MW（生成器口径不自洽），需自洽口径 + 锚定题目量级
- **局限**：c_r 拟合命中率 D/F 区 8%（主模式校准声明）

## D-2 防泄露三段协议
- **决策**：0-2351 五折滚动 CV 类选 / 2352-2375 校准 / 2376-2399 冻结
- **备选**：随机 KFold（时序泄露）被否；单次验证（噪声内增益误判）被否
- **理由**：类选报告 mean±std；校准段仅 κ_ε 校准；冻结段一次性评估（24h 窗口噪声主导，
  只承担"不崩溃验证"）

## D-3 验证门判据
- **决策**：任务侧=覆盖率显著增益（>基线 std）且宽度 ≤1.15× 或 pinball 降幅≥5%；
  能源侧=MAPE 相对降幅≥5%
- **备选**：单指标 cov≥90%（TabPFN 宽区间刷分事件后修正为显著门限）
- **理由**：噪声内增益不算增益（model-evaluation 纪律）

## D-4 融合设计
- **决策**：不确定性元特征（q50+宽度+滚动误差+时间）Ridge stacking → 增益>0.1% 才用，
  回退链（等权→最优单→统计基线）
- **备选**：等权（增益低）；RF 元学习器（6/6 序列统治，作为研究结论）
- **理由**：树类同质（残差相关 0.79-0.92）→ 融合空间有限；异构（deep_tcn）加入后
  carbon 增益 21.4%

## D-5 预留闭环
- **决策**：κ_ε = 1 − q_{1−ε}^agg/C_r，ε 8 值网格，达标集（覆盖率≥95%）取最大 ε
- **备选**：固定 ε（无校准，置信度不足）；3 值网格（分辨率不足，用户指示扩至 8 值）
- **理由**：伪校准（训练段滚动 24h）佐证稳定性、真实校准（2352-2375）裁决

## D-6 构造数据策略
- **决策**：逆向生成规则（c_r/段标签/零膨胀）作为口径依据 + 参数敏感性反证
- **备选**：把数据当黑盒（多数队做法，丢失口径理解）
- **理由**：理解构造=理解评价口径；结论限定"本数据（合成）"声明贯穿
