## 一、问题重述（忠实题面）

Q4：前三问基础上建立多区域算—储—电协同模型，统一考虑任务迁移、电价、碳排放、
可用新能源、储能、区域购售电边界、网络时延、任务异构性；六指标权衡
（运行成本/碳排放/网络时延/服务质量/新能源利用率/区域峰值净购电）；
比较三场景（碳约束/电价机制/新能源波动）策略变化。说明7 不建潮流/带宽/迁移量模型。

## 二、六指标章程（step4.1，Q4 度量衡定案）

| 指标 | 口径 | 时域 | 来源 |
|---|---|---|---|
| Cost | Σ_r Σ_t (price·G − sellp·S) 万元 | 全 2407h | Q3 评估器 |
| Carbon | Σ_r Σ_t (carb·G) 吨 | 全 2407h | Q3 评估器 |
| Lat | GPU-hours 加权时延（T1 纯加权） | 任务级 | Q2 时延裁决 |
| QOS | α·完成率 + (1−α)·时延裕度，α=0.5 默认 | 任务级 | 自定 + 敏感性 |
| NU | Σ(W−Q)/ΣW（I5，消纳模板口径） | 主时段 | Q1 R1 模板 |
| P_peak | max_r max_{t<2400}(G−S) | 主时段 0-2399 | Q3 X13 教训 |

**QOS 0.5 论证**：①无先验偏好等权=中性标准 ②α 敏感性 {0,0.3,0.5,0.7,1} 扫描
（1−QOS 线性移动为定义使然；其余五目标结构解耦不受 α 影响）③α 为上层伴随基因
交叉验证（PLAN §9.5）。完成率项恒 100%（硬约束）为"定盘星"（兜底违约方案）。

**D 口径（Q4 与 Q3 的本质区别）**：D(r,t) = (NonAI + 任务调度 AI_IT_Load) × PUE
——Q3 D 固定（Baseline），Q4 D 随上层任务调度变化（说明2/说明3）。

**独立维度预检（step4.1 实证）**：27 个可行策略采样 → 六目标累计方差 90% 需 2 维；
QOS-Lat 相关 0.986（共线预判证实）；成本-碳相关 0.65（被下层储能自适应解耦——
与 Q2/Q3 的 0.91-1.00 不同，Q4 下层优化打破共线）。按退化呈现叙事入论文。

## 三、双层 Stackelberg 模型（step4.0）

```
上层 NSGA-II（6 旋钮 = Q2 五旋钮 + α 伴随基因）→ schedule_constructive
      → 逐区 AI_IT_Load → D = (NonAI + AI)×PUE
下层 M3_final 储能 LP（solve_m3：时段状态机+结算段禁充+终态严格+生成器斜坡）
      + solve_lower_constrained（碳限额/峰值限额参数化，场景与影子价格共用）
返回六目标 → 上层评价 → 联合帕累托
```

- **双层必要性（物理时序）**：算力决策先行、电力响应（H4.1）；一体化 MILP 规模不可解。
- **决策 C1**：主流程 M3_final（LP 快）；M0x（互斥 MILP）仅代表性解上界对照。
- **决策 C2**：进化内直接用真实 LP（HiGHS 单区 0.1-0.2s，6 区 ~1s/评价）；
  正式预算 40pop×30gen×3seed 可 12 worker 并行；smoke 模式 12/4/1 验证。
- **决策 C3**：压力矩阵重评估代表性策略集（Q4 折中/Q2 折中/构造三档）
  ——"策略迁移"本身是研究结论，不做 18 轮完整进化。
- **决策 C4**：α 默认 0.5 + 敏感性扫描报告。
- 边界（可行区实证内）：mig_gpu≤8 / headroom≤0.03 提高初始种群可行率
  （Q2 的 15/0.08 随机可行率低，1e12 支配排挤）。

## 四、影子价格与关键机理发现（step4.2）

**核心发现（机理级）**：功率平衡 + 弃电下界隐含 `G ≥ D − cap_h`（消纳模板锁定
购电下界）→ 成本单目标 LP 已把 G 压到下界 → **碳排/峰值即可行域下界**：
- 碳限额/峰值限额收紧 2% 成本不变（约束不活跃），继续收紧直接 **infeasible**
  （activity_knee 实证，全部区域一致）；
- **⇒ 储能层内减碳降峰空间 = 0；减排/降峰杠杆在上层任务调度**（错峰把负荷移到
  cap_h 大的时段、迁移换区域）——**Q4 双层结构的必要性实证**；
- 影子价格 = 数值差分（RHS 收紧，HiGHS 不返回对偶向量），解释域限定"给定调度"；
- 微扰验证：约束不活跃区间 π≈0 如实标注（非 0.0 假通过）。

## 五、压力矩阵（step4.3，18 格 = 3τ × 2k × 3σ）

| 维度 | 档位 | 依据 |
|---|---|---|
| 碳约束 | τ∈{10%,20%,30%} | Sobol 碳由碳强度主导（S1=0.90）；E8 ±10% 起步 |
| 电价机制 | 峰谷比 ×{1.2, 1.5}（step4.1 预扫定档，失真检查：≤10） | Sobol 东区 price 主导（S1≈1.00） |
| 新能源波动 | σ∈{10%,20%,30%} | Q3 MPC SIGMAS 继承（波动有真实成本 X15） |

- 碳场景正确语义：储能层可行则直解；不可行 → **上层错峰杠杆演示**（shift 增强
  变体重试，报告 lever_needed/lever_ok）——诚实呈现"储能层做不到的由上层承担"；
- 波动场景：W 模板×AR(1)（φ=0.8）×64 场景→K-means 12 代表 → 场景加权期望；
- 场景自造声明（题面未给场景数据）；每档价格统计量合理性检查（均值漂移=0）。

**实证结果**：波动 σ 每档成本上升（163,849→164,330→164,873 万）——波动有真实
成本复现；σ=0.2 时最优策略从 Q4 折中切换为构造（策略迁移发生）；峰谷比放大
（4.67→4.91）成本反降（储能套利空间变大）。

## 六、消融与验收（step4.4 + tests/test_q4.py）

- **组件消融**（万元）：无储能 184,055 > 无迁移 172,393 > 无错峰 164,262 ≈ 基线
  164,260 —— 储能贡献 ~2 亿、迁移 ~1.2 亿、错峰 ~0（与 E1 分解一致）；
- **联合 vs 交替**：joint 163,868 < alternate 164,260（−0.24%）——联合必要；
- **单调性验收载体**：SellLimit 收紧（碳限额不可行域，见 §四）；
  1.0→0.9→0.8：163,933→168,230→172,761 单调不减 ✓；
- **三层验收测试（tests/test_q4.py，10 项全绿）**：
  - 口径层：六指标手算锚点 rel<1e-9；Baseline 负荷下 solve_m3 == q3 m3_final
    （组合重现对账）；QOS∈[0,1]；峰谷比重构保均值；
  - 求解层：LP 约束残差 <1e-6（功率平衡/SOC/弃电下界）；M0x 充放互斥；
    白名单零违约；SOC(2406)≥Init；SellLimit 单调性；可复现逐位一致。

## 七、规则层（step4.5）

- CART（max_depth=4, min_samples_leaf=500）从最优解学"是否迁移"→ 规则表；
- **规则模拟可行性修复链**（本步实证的三处 bug）：
  ① 优先级排序（RT 先占位，防弹性挤压）② shift 窗口两段式（防拖入冻结段
  挤压 RT——冻结段需求抬升 z=2.86 是诱因）③ 本地分支容量检查 + 全窗口修复
  （CART 迁移集与 Q2 阈值不同 → 本地堆积超容）；
- **规则化代价**：构造 0.0%、Q4 折中 0.002%（规则近乎无损——比 Q3 的 0.78-2.93%
  更优）；q2 折中规则模拟在下层 LP 不可行（时段分布变化致购电超上限），
  诚实标记 rule_infeasible=True。

## 九、论文口径（Q4 章节）

1. **双层必要性**：影子价格实证储能层减碳/降峰空间=0 → 上层调度是碳/峰值杠杆；
2. **六目标退化**：独立维度≈2-3（QOS-Lat 共线 0.986；成本-碳被下层解耦）；
3. **组件贡献**：储能 2 亿 > 迁移 1.2 亿 > 错峰 ~0；联合优于交替 0.24%；
4. **波动成本**：σ 每档 +0.2-0.3%（Q3 X15 复现）；峰谷比放大降本（套利增强）；
5. **规则无损**：规则化代价 0-0.002%（CART 从最优解直接学习）；
6. **三层验收**：锚点 1e-9 / 残差 1e-6 / 单调性 / 可复现 全绿。
