# sum_4 — M3 Q2 碳感知多目标调度（构造→进化→规则三段式）

> 阶段闭环：step2.0 构造层 + step2.1 NSGA-II + step2.2 规则提取 + step2.3 时延裁决/baseline_proof。
> 数据裁决主线：Q2 收益 = 确定性空间套利（迁移 4.5pp），帕累托宽度受本地容量结构约束。

## 构造层（step2.0）

- 方法：白名单 + 价差/碳差排序 + 容量贪心；RT 固定；策略参数化（mig_gpu 阈值/
  错峰/松弛）供 NSGA-II 复用
- 结果（模板口径）：成本 19.29→18.37 亿（**−4.75%**，命中 E1a 区间上界）、
  碳 210.8→201.5 万吨（−4.43%）、NU 32.07→32.86%（+0.79pp）、
  **时延 5.0→27.8ms（5.6×——迁移的代价，Q2 核心权衡）**、viol=0

## 进化层（step2.1 自研 NSGA-II）

- 实现：Deb 2002 快速非支配排序 + 拥挤度 + SBX(η=15)/PM(η=20) + 精英保留；
  40×60×3 seed，12 worker 评估池（用户指定留 4 核），~8 分钟
- **v1 失败教训（决策记录）**：4 维策略（λ/错峰/松弛）→ 前沿塌缩
  （λ 是死参数：D 区价格碳双第一 → 排序不变 → 0 任务差异）
- **v2 阈值版**：mig_gpu_min/mig_dur_min 控制迁移量 → 真实帕累托
  （cost 183706-184739、lat 25.3-27.8ms 连续谱）
- **可行区扫描**：mig_gpu≤15 才 viol=0——**E/F 超容构成 = AT 94-95%**
  （AT 白名单全 6 区可达，但 E/F 容量不足强制溢出）
- **窄前沿 = 题目结构真结论（判别实验链）**：① 错峰无救活作用
  （viol 44→43，AT 刚性）② 迁移距离维度已被价格排序隐含覆盖
  （E/F 374/393 元 < D 423 元，先迁 E/F 后溢出 D）③ 溢出目标唯一
  → 前沿 = 强制溢出量 × 固定边际成本的线性权衡
- 3 seed 前沿范围一致（可复现）✅；罚函数 v1 缺陷（viol 解在 lat 维度
  保持优势）→ 改为绝对不可行标记（1e12 全目标）

## 规则层（step2.2 CART）

- 三个代表解（TOPSIS 折中/成本端点/时延端点）的迁移决策树：
  - **GPU < 11.5 → 不迁移**（23,368 任务，纯度 1.00——小规格留本地）
  - GPU ≥ 11.5 ∧ 非 E 源 ∧ BI → 迁移（8,755，纯 1.00）
  - 源=E ∧ GPU ≥ 49.5 → 溢出迁移（2,827，纯 0.66）
- 三解规则结构一致 → 策略表达稳定；规则即题目要的"调度策略"交付物

## 时延目标裁决（step2.3）

- **T2/T3 违约惩罚形式无区分度（数据裁决）**：白名单硬约束下前沿解
  零违约（最小时延裕度 2ms）→ 违约项恒 0 → **T1 纯加权是唯一有效形式**
- baseline_proof（消融 H 输入）：
  | 方案 vs local | 成本 | 碳 | NU | 时延 |
  |---|---|---|---|---|
  | Q1 greedy | −0.001% | −0.0% | 0.0pp | 1.0× |
  | Q1 quantile | −0.08% | −0.02% | 0.0pp | 1.0× |
  | **Q2 折中** | **−4.57%** | **−4.31%** | **+0.78pp** | **5.26×** |
- **Q2 相对 Q1 的增量 ≈ 4.5pp = 迁移/错峰全部收益（确定性空间套利）**
