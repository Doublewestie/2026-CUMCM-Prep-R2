## R1 消纳结构逆向（问题一：形式错误 → 结构识别）

**旧口径（错误）**：U = min(W, c_r·D)，c_r = 主时段 U/D 中位数 → D/F 命中率仅 8-24%。

**实证发现（step1.7 前置调查，全部数据裁决）**：
- **U/D 对每个小时跨天完全恒定**（六区 98 天 × 24h，max std = 0.000000）
  → 生成规则 **U(r,t) = c_r(h)·D(r,t)**，c_r(h) 是确定性日内模板，**与 W 无关**
  （corr(残差,W)≈0——W 从未成为瓶颈，min 形式根本不存在）
- **c_r(h) 形状三族**：
  - A/B/C：夜间平台（0-6h = 0.12/0.15/0.18 等差）+ 白天单峰（12-15h 0.146/0.176/0.206），
    归一化形状完全相同（max|diff|=0）
  - D/F：**完美单正弦**（R²=1.0000，a=0.39/0.56，amp=0.03/0.06，相位全域一致）
  - E：平台 0.55 + 白天对称钟形（峰 0.73@12h，7-17h）
- 尾段 2352-2399 与训练模板完全一致（max dev=0.000000）；Closure 段 U=min(W,D)（hit=1.0）
- 外送结构：D/E/F 的 W 四去向分解 U+充电+弃电+外送 == W（外送上限=SellLimit）

**落地（step1.0 R1 升级）**：fit_consume_ratio 拟合 24 值模板 + 正弦参数化（论文素材）；
evaluate_schedule 模板口径（主时段 c_r(h)·D + Closure min(W,D)）。
**锚点验证**：六区模板命中率 1.0；基线指标向题目锚点靠拢
（NU 31.15→32.07%、弃电 795→784.7 万 MWh、成本 19.78→19.29 亿）。
**E1 结论不变**：gap 0.073→0.081pp（同口径相对比较稳健，a5 敏感性 ±10% 全 <0.5pp）。
**教训**：拟合命中率低 → 先做全散点+函数族拟合（min R²=0 铁证），不声明"难以预测"。

## R0 校准段修复（问题二：真 bug，非"漂移"）

**旧实现（错误）**：step1.2 注释声称"真实校准 2352-2375"，但 SEG_CAL=2376 →
`arange(2376, 2400)` 实际在**冻结段**上选 ε —— 三段协议破坏（冻结段被污染）。

**实证**：正确口径 2352-2375 上伪校准 0.939 vs 真校准 0.938（差 0.2pp）；
sum_2 的"漂移 6.4pp"（0.939 vs 0.875）是**冻结段 vs 训练段的段间差异被误读**。

**修复**：SEG_CAL_START=2352/SEG_CAL_END=2376；重跑后 ε=0.05 仍入选
（2352-2375 上 cov=0.979），E1 gap 不变；冻结段回归"纯验证"职责；
`calibration_fix` 字段记录修正（决策记录 = 论文方法学诚实素材）。
**教训**：校准窗与参考窗须对称设计；注释与实现不一致是协议级 bug 温床。

## R2 冻结段结构（问题三：不是"预测烂"，是生成器收尾结构）

**旧归因（错误）**：冻结段 CV-最优一致率 8.3% → "24h 短窗噪声主导"（设计缺陷包装成发现）。

**实证（step1.7）**：
- **S1 判别**：冻结段需求水平抬升 +20%（GPU-hour 均值 2499 vs 2089），z=2.86、
  **100 百分位**（98 个训练窗口无一达到）→ 生成器收尾结构，非随机噪声
- **S2 条件覆盖率**：覆盖率条件于需求水平（高需求窗 0.941 vs 低需求窗 0.959，gap −1.8pp）
- **S3 滚动重估**：常数历史分位数 0.917 → 滚动 336h nowcast 分位数 0.944（修复 2.8pp，
  shift≥1 防泄漏）——"外推失效于分布平移"的建模修复
- **S4 最终验证**：预留调度冻结段超容率 4.86% ≈ ε=5% 设计（κ_ε 在分布外仍兑现保障）
- **S5 价格机理**：冻结段价格 = 日模板 + 段内结构（日模板 MAPE 1.27% < 段标签均值 2.48%），
  0.19% 来自模型残差修正精确命中段内结构（非模板巧合）

**教训**：短窗"失效"先做判别实验（z-score/分布外检验），短窗只承担"不崩溃验证"，
不再承担"排名裁决"；冻结段是研究对象的最后 24h，其特殊性本身是发现。
