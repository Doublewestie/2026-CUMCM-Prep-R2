# sum_1 — 数据侦察与证据链 D1-D9（M1 里程碑）

## 问题起点
C 题数据 6 表（5 万任务 + 1.4 万行电力数据）存在哪些隐藏结构？选题前口头侦察的 D1-D9 是否经得起代码实证？

## 方案与过程
- step0_loader：6 表加载（显式 sheet）、质量检查、白名单预计算、本地执行占用展开（195,047 行）、18+2 序列聚合 → output/clean/ 全量落盘
- step0_eda：9 张证据链图（figures/eda/figD1-D9）+ eda_summary.json 数字汇总

## 关键发现（实证确认）
| # | 证据 | 实证数字 |
|---|---|---|
| D1 | 任务到达白噪声 | 18 序列 mean lag1=0.011 / lag24=-0.006；ACF 在 ±1.96/√n 带内 |
| D2 | 新能源模板化 | 六区曲线 100% 重合；day0==day1；范围 500-1100MW 确定性正弦 |
| D3 | 本地执行超容 | E 30h / F 67h（最大超 62%）；A/B/C/D 仅 3-6h |
| D4 | 弃电天文数字 | 总弃电 775.5 万 MWh；利用率 32.9%；弃电充电≈0 |
| D5 | 相位错位 | NonAI 负荷凌晨峰/傍晚谷差 67%；东区弃电率 88-91%（新能源白天出力 vs 凌晨负荷峰错位！） |
| D6 | 时延白名单 | RT 最少 1 区（D 孤立）、BI 最少 5 区、AT 全 6 区 |
| D7 | 电价标签内波动 | Flat 段 ±19.7%；全国同步 Peak=17-21/Valley=0-6 |
| D8 | 实时推理无弹性 | slack 中位 4h（1-7h）；本地执行永无超容 |
| D9 | 数据零脏 | 零 NaN、零矛盾任务、规格分布 1-127 GPU |

**新发现（侦察期未覆盖）**：东区（A/B/C）弃电率 88-91% 远高于西区（39-53%）——东区无外送能力（SellLimit=0）且负荷峰在凌晨与光伏白天出力错位。这强化 D5 叙事：**相位错位在东区直接转化为弃电损失**，储能（午间弃电充电）在东区的价值比西区更显著。

## 对比（如有演化）
选题前侦察（base 环境 pandas 2.2）→ 正式实证（mathorcup 环境 pandas 3.0.2）→ 数字完全一致，D1 修正为基于 18 序列均值（此前用单序列），D4 利用率口径补全（含充电+外送，19.2%→32.9%）。
