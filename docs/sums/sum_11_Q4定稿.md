## 四、T4：碳杠杆三族全败 → 杠杆上限 0.239%（结构性结论）

- 杠杆三族（A 错峰 24h / B 迁移 mig_gpu≥8·dur≥6.65 / C 联合）在
  τ∈{0.1,0.2,0.3} **全部 infeasible**（q4_pressure.json lever_variants）
- **归因诊断**：B_migrate 总碳排反而 +4.7%（调度器迁移目标=成本最优，非碳最优；
  mig_dur_min=6.65 组合产生反效果迁移集）——**杠杆设计缺陷而非结构性不可能**
- **判别实验（mig 旋钮全档扫描）**：mig_gpu_min∈{0..15} → 迁移集 26,602→18,717
  任务，碳排仅变 ±0.12% → **任务层碳杠杆上限 = 0.239%**
- 根因链：AI 负荷只占总负荷小部分（**NonAI 底数稀释**）+ 成本驱动调度器 +
  区域碳强度差有限（0.42-0.62 区间窄）
- **政策级结论**：等比例区域碳限额 τ≥1% 即超任务调度杠杆能力 → τ∈{10%,20%,30%}
  不可达系结构性；减排需源头（NonAI/生成器侧）或跨区电量调度
- 回灌：step4.3 产物增 carbon_lever_floor 字段（scan/verdict）
