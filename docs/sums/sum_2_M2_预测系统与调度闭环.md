# sum_2 — M2 预测系统与调度闭环（Q1 全链研究总结）

## 研究哲学：数据不是黑盒，是生成器的"问题陈述"

本题目数据为**合成仿真系统**（确定性模板 + 随机过程 + 参数化规则三件套构造）。
本阶段的核心研究姿态：**不把数据当黑盒输入，而是把它当作出题者的问题陈述来解读**——
逆向生成规则（消纳系数 c_r、段标签结构、零膨胀参数）不是投机，而是理解评价口径本身。
评估器与生成器意图对齐的实证：基线锚点全中（NU 31.15% vs 32.9%、弃电 795 vs 775.5 万 MWh、
E30h/F67h 精确吻合）——对齐不是巧合，是逆向工程的正确性证据。

**构造数据指纹**（step1.6）：段内残差 KS 检验、时延矩阵不对称对、零膨胀参数表（10-82%）、
规格 Gamma 分布（shape 0.68 长尾）、消纳系数 0.12-0.56。**结论对生成参数稳健**
（到达重采样下类选结论不变）。所有结论限定"本数据（合成）"，不推广为真实世界规律。

## 国特思路：机理深度而非模型堆砌

1. **η 档案连续谱**（任务侧 0.0 / renewable 1.0 / price 0.99 / carbon 0.877 / nonai 0.889）——
   可预测性不是二分，是连续谱，预测策略随 η 分级（分布刻画→模板拟合→残差修正）
2. **套利结构分解**：空间（迁移 4.6%）>> 时间（错峰 0.001%）；**序贯次优性发现**——
   oracle 价格感知贪心（1.95%）劣于结构化迁移（4.58%）：容量约束下逐任务最优被先到者
   抢占拖累，集中迁移到低价大容量池（D 区 1472）全局更优——"贪心局部最优≠全局最优"
   的算电协同实例
3. **E1 胜负手**：预测精度边际价值≈0（gap 0.073pp），收益主驱动=结构套利——白噪声下
   堆复杂预测是负收益的科学论证
4. **领域基函数载体教训**：B2 在 OLS 载体上"8 族全不显著"→ 换正确载体（LGBM 残差/
   特征/融合层）后 **16-21% 增益翻案**——统计检验的结论依赖载体强度，这是方法学教训
5. **QRF 均值化陷阱修复**（cov 0.08→0.89）：树均值分位数 vs Meinshausen 叶内样本分位数
   ——"训练用均值、推断用分位数"的 loss-推断错配
6. **冻结段方法论发现**：24h 窗口最优排名噪声主导（历史模拟一致率 0-28%）——短窗评估
   不承担排名职责，只承担"不崩溃验证"

## 核心结论（数据裁决）

- **类选**：任务侧 143/144 拒（白噪声确认，历史分位数最优）；能源侧 126/192 通过，
  renewable 模板完美全拒；**TabPFN 统治结构类 18/18**（外部挑战者胜出=竞技榜机制公正）
- **融合**：吸收范式（加权）>选择；RF 元学习器 6/6 序列统治（多序列统计）；异构互补
  （deep_tcn 残差相关 0.01-0.09，carbon 融合增益 21.4%）；跨序列共享需 per-sequence
  标准化（52→2.6，结论修正为与独立相当）
- **调度**：预留闭环（ε=0.05，实测覆盖 95.1%）；瓶颈浅局部（191 个 AT 任务、E/F、1-3h）
- **套利**：空间 2-4.6%（启发式区间）>> 时间 <0.01% → **Q2 迁移为主已定调**
