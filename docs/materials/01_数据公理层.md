### 素材 1-1：恒等式集 I1-I13 — 数据精确自洽的公理层【实证】
**结论陈述**：
附件数据列之间满足 13 条恒等关系（I1: IT=NonAI+AI、I2: 功率平衡、I5: 利用率≡1−Q/W、I6: SOC 递推、I13: Total=IT×PUE 等），六区逐点残差 rel 1e-7~1e-9——**数据由确定性生成器构造，不存在随机噪声层**。这使"评价口径"成为可解析验证的公理系统，而非黑盒。

**支撑数字**：
| 恒等式 | 残差 | 证据 |
|---|---|---|
| I1 IT=NonAI+AI | rel_mean 6.3e-10 / max_abs 3.3e-7 | 六区逐点 |
| I2 功率平衡 | 同量级（W=Available 全进口径） | 14442 行 |
| I5 NU=1−Q/W | 主时段 | 模板口径 |
| I13 Total=IT×PUE | rel 1e-9 级 | 六区 |
| 全体 13 条 | 7 关证明全过 | identity_proof.json |

**数学公式**：
```
I1: IT_Load(r,t) = NonAI_IT_Load(r,t) + Baseline_AI_IT_Load(r,t)
I2: GridPurchase + AvailableRenewable + Discharge = Total_Load + Charge + GridSell + Curtailment
I5: 新能源利用率 = Σ(W−Q)/ΣW = 1 − Q/W（恒等）
I6: SOC(t) = SOC(t−1) + ηc·Charge(t) − Discharge(t)/ηd（分区效率）
```

**证明链（7 关证明协议，methodological 亮点）**：
① 解析推导（恒等式从口径公式直接推出）→ ② 数值验证（六区逐点残差统计：
mean/max/p99/std/rel）→ ③ 构造性交叉（用公式重建列，与数据表对照）→
④ 反例排除（W=Used 变体不成立——口径唯一性）→ ⑤ 敏感性（时段/区域/边界
分段检查）→ ⑥ 守卫固化（tests/test_identity.py 58 项）→ ⑦ 文档入册
（CONSTITUTION 恒等式集）。

**图**：figD1-D9（数据侦察图组）
**口径/边界**：恒等式在数据表口径下成立（生成器产物）；优化解不直接满足
I2 的"数据表 Used 口径"（模型用 Available 全进）——评估器与生成器口径对齐。
**产物映射**：output/clean/identity_proof.json；tests/test_identity.py
**研究背景**：S9 全谱侦察的核心产出——恒等式不是"假设"而是"数据自洽性的
可证伪检验"；残差 1e-9 级证明生成器无随机层（直接影响第三章可预测性分层）。

### 素材 1-2：新能源 W 精确公式【实证】
**结论陈述**：六区可用新能源服从同一精确公式 `W = round(800 + 300·sin(2π(h−4)/24), 2)`（MW），最大残差 0.0043 MW（round 舍入层）——新能源是严格确定性日内模板。

**支撑数字**：max 残差 0.0043 MW；六区同构（公式参数相同）；命中率（残差<0.01 比例）≈100%
**数学公式**：`W(r,h) = round(800 + 300·sin(2π(h−4)/24), 2)`，h=0..23（日内循环）
**证明链**：① 函数族拟合（线性/有理/幂/正弦全散点+族拟合——"先怀疑形式再怀疑噪声"）② 六区同构验证 ③ 残差统计（0.0043 = round 到 2 位小数的量化噪声，非随机）
**图**：figD2_renewable_template.png
**口径/边界**：主时段 0-2399 全部适用；Closure 段同模板（数据确认）
**产物映射**：step0.6_thresholds.py:t1_w_template；step3.1_scenario_mpc.py:gen_scenarios
**研究背景**：S9 临界点扫描发现——W 的解析形式让"波动场景生成"（AR(1) 扰动模板）与"Sobol 参数化"有了精确基底。

### 素材 1-3：消纳模板 U = c_r(h)·D — 命中率 100%【实证】（全题机理根源之一）
**结论陈述**：新能源消纳量满足日内比例模板 `U(r,t) = c_r(h)·D(r,t)`（c_r 为 24 小时比例向量），主时段命中率 100%——**消纳是负荷侧的确定性比例规则，与 W 无关**。这是全题最深的口径事实（直接推导出 T1 购电下界定理，见素材 4-1）。

**支撑数字**：命中率 100%（14400 点/区）；c_r 六区各异（A 0.12-0.146、D 0.364-0.416、E 0.55-0.73、F 0.508-0.612 量级）；D/F 区单正弦 R²=1.0
**数学公式**：
```
U(r,t) = c_r(h)·D(r,t)，h = t mod 24
（消纳能力 cap_h = min(W, c_r(h)·D)——W 充裕时由负荷比例决定）
```
**证明链**：① 函数形式修正史（初版线性 c_r·W 命中率仅 8% → 全散点+函数族拟合 → 发现 min 形式与负荷比例——"命中率低先怀疑形式"案例）② 主时段 14400 点逐点验证命中率 100% ③ Closure 段口径（min(W,D) 全消纳，sum_10 修复）
**图**：figB1_profile.png（消纳比例日内轮廓）
**口径/边界**：主时段 0-2399 成立；Q4 中 D 随任务调度变化——模板外推假设（c_h 与负荷组成无关）已做 ±10% 敏感性（素材 5-10）
**产物映射**：step1.0_baseline_schedule.py:fit_consume_ratio；output/baseline/baseline_metrics.json
**研究背景**：R1 建模缺口闭环——消纳口径是 Q3 弃电下界、Q4 影子价格的共同根基。

### 素材 1-7：生成器指纹（构造性证据）【实证】
**结论陈述**：Baseline_AI 由"分数 Overlap 生成口径"构造（I11 破案）：`Baseline_AI = Σ g×P×overlap_frac`（分数重叠，ceil 整点总量等价/逐时差 15%）——**生成器的任务-电力映射机制被完全逆向**。

**支撑数字**：分数 Overlap 口径与数据表吻合（总量等价）；逐时差 15% 由 ceil 口径解释
**数学公式**：`Baseline_AI(t) = Σ_i g_i·P_type·overlap_frac(i,t)`
**证明链**：① 三因子分解（M1-M4）② 分数 vs ceil 口径对照 ③ 逐时差异 15% 的机制解释
**产物映射**：step0.6_mechanism.py；output/clean/identity_proof.json（I11）
**研究背景**：S9 "分数 Overlap 破案"——生成器行为=隐式物理约束的观测源。

**结论陈述**：RegionE 数据表 SOC 列存在起点录入误差（hour0 差 1 MWh），经递推传播为全程 ≈1.0 MWh 平移（0.9999~1.0039）；其余五区数据表与递推吻合（mean|diff|≤0.005）——**处理口径：以储能递推公式重新计算 SOC 状态（官方推荐措辞）**。

**支撑数字**：hour0：数据表 478.3339 vs 递推 479.3338（差 0.9999，与官方计算一致）；其余五区 mean|diff| ≤ 0.005 MWh
**数学公式**：`SOC(t) = SOC(t−1) + ηc·ChargePower(t) − DischargePower(t)/ηd`（附件口径）
**证明链**：① 分区效率递推（A/B/C 0.93/0.92；D/E/F 0.94/0.93）与数据表全区域对照 ② 官方反馈确认（"第 0 小时局部录入误差/口径残差"，建议表述"以储能递推公式重新计算 SOC 状态"）③ Q3/Q4 全部模型用递推（不读数据表 SOC 列）

**论文口径声明**（可直接引用）："RegionE 基准 SOC 数据存在起始录入误差（约 1 MWh），本文以附件储能递推公式重新计算 SOC 状态（官方推荐处理口径）；其余五区递推与数据表吻合（≤0.005 MWh）"
