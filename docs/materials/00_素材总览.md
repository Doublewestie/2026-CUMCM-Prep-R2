# 论文素材包 — 素材总览与使用说明

> 定位：建模手/代码手向论文手交付的**研究素材**（研究路线、实验、思路过程）。
> 不决定论文结构——按研究主题组织，论文手自行编排章节。
> 每个素材 = 结论 + 数字 + 公式 + 证明链 + 图 + 口径 + 产物映射，可整卡取用。
> 所有数字可追溯至唯一产物文件（数据核查纪律）；结论分级【实证/推断/推测】。

## 四、口径红线（论文手必读）

1. 主口径：M3_final（时段状态机+结算段禁充+终态严格+生成器斜坡）；波动/峰值指标一律主时段 0-2399
2. 储能价值以**无储能 LP 对照**为准（模板版含 LP 自由度红利 1.43 亿，不得混用）
3. 波动场景用**64 原始场景**（K-means 中心截断低估 25.6%）
4. 影子价格以**数值差分**为准（对偶退化）；π_sell 是唯一可行载体
5. α 固定 0.5（评估器参数不可优化）；D 随调度变化（Q4 与 Q3 本质区别）
6. RegionE SOC 偏移已修正（以递推公式重建，官方推荐措辞）
7. 每数字可追溯唯一产物文件（09 总表）
