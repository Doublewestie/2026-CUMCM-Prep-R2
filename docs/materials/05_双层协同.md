### 素材 5-1：六指标章程（含 α 固定理由）【实证】

**结论陈述**：Q4 六指标全部继承前三问口径（零新发明），唯一自定 QOS 用
α 敏感性+固定 0.5 定案；**α 固定 0.5 的数学理由：α 作为伴随基因时，
完成率恒 1 → α=1 使 1−QOS≡0 恒成立 → 目标游戏化（评估器参数不可被优化）**。

**支撑数字**：QOS 定义域 [0,1]；α 敏感性扫描（1−QOS 跨度 0.2685 为定义使然）；
完成率恒 1（硬约束保证）→ QOS 有效维度=裕度
**数学公式**：
```
Cost = Σ_r Σ_t (price·G − sellp·S)（万元，全 2407h）
Carbon = Σ carb·G；Lat = GPU-hours 加权时延；NU = Σ(W−Q)/ΣW（I5）
P_peak = max_r max_{t<2400}(G−S)（主时段 0-2399，X13 教训）
QOS = α·完成率 + (1−α)·mean(min(1, (m_i−ω_i)/m_i))，α=0.5 固定
D(r,t) = (NonAI + 调度后 AI_IT_Load) × PUE  ← Q4 与 Q3 的本质区别
```

**证明链**：① α 游戏化反例（α=1 使 1−QOS≡0——总账 #45）② α 敏感性扫描
（结构解耦：其余五目标与 α 无关）③ 六目标独立维度预检（2 维——QOS-Lat
共线 0.986、成本-碳 0.59 被下层储能解耦）
**图**：fig_q4_dimcheck.png
**产物映射**：output/q4/q4_indicators.json（six_metrics_caliber/dim_check）
**研究背景**：Q2 目标退化（4→2 维）在 Q4 升级为六目标→2 维——"退化呈现"

### 素材 5-3：T2 储能结构锁定【实证】（Q4 核心定理）

**结论陈述**：
> **定理（储能结构锁定）**：当下层储能采用生成器同构时段模板（M3_final）
> 时，任务层（迁移+错峰）的电力侧可优化面被结构性压缩至 0.14-0.55%
> （vs Q2 无储能语境 4.57% 的 1/8~1/30）；联合帕累托主轴=时延/QOS。
> **机制**：激进迁移把负荷移出储能放电时段 → 相位错配 → 储能价值下降
> （oracle 真实评估反噬）；容量硬约束进一步钳制极端重排。

**支撑数字**：正式前沿成本跨度 0.14%（163,864~164,039）；判别 A 极端策略
跨度 0.55%；oracle 迁移 859 任务解析增益 4,574 万 → 真实评估 +3.4%（峰值
+15%/碳 +2.4%）；宽时段下层（充电 h0-8+20-23）跨度仍 0.27%（时段宽度非根因）

**三证据链（证明）**：
| 证据 | 实验 | 结果 |
|---|---|---|
| A 判别 | Q2 极端策略跨评估器（同框架重评） | 跨度 0.55%（Q2 的 1/8） |
| B oracle | 解析边际贪心迁移（选择近似/评估精确）+ 轨迹跟踪 | **从第一个迁移即单调恶化**（520 个 +2.3%→859 个 +3.5%）——方向性错误（解析近似缺储能时段项），非过冲 |
| C 容量钳制 | 极端重排（全迁 D/窗口错峰） | 超容 2.6 倍 / 1,553 小时违例——任务层重排自由度受容量硬约束 |

反证排除：宽时段下层（放宽充电域）下任务层跨度仍 0.27%——**时段模板宽度
不是锁定根因**（更深结构：储能吞吐 Cap + 消纳模板 + 成本面平坦）。

**数学公式**：可优化面定义：`跨度 = (max−min)/min 成本 over 任务层策略集`；
oracle 边际收益近似 `Δ ≈ Σ_t (1−c_h(t))·price(t)·ΔAI(t)`（缺储能时段项——方向误导源）
**图**：fig_q4_collapse.png（策略集成本对比 + oracle 线）
**口径/边界**：锁定指"电力侧成本维度"（时延/QOS 维度仍有自由度）；M0x
（互斥自由时段）下任务层价值未测（MILP 成本——见研究背景）
**产物映射**：output/q4/q4_collapse.json（判别 A/B + trajectory + verdict）
**研究背景**：Q4 前沿坍缩（smoke 0.002%）的归因判别——先怀疑"搜索不足"
（正式预算排除）再怀疑"表达力不足"（oracle 排除）最后落在"结构锁定"
（三证据链）；与 Q3 E6 权衡面坍缩同构传承（跨问机理自洽）。

### 素材 5-4：影子价格与对偶退化【实证】

**结论陈述**：影子价格以**数值差分**为准（解析对偶被验证门否决）：
① 碳/峰值限额载体 2% 即全 infeasible（T1 推论——储能层内减碳/降峰空间=0）；
② **储能 LP 退化（多重最优）【实证】**：HiGHS marginals 为顶点基内梯度，
与最优值函数斜率系统性偏差 28-45%（10/10 随机小时），不可投产；
③ **π_sell 是唯一可行载体**（SellLimit 收紧单调 164,768→172,761 万——外送
通道瓶颈的货币化边际代价，Q3 E5 呼应）。

**支撑数字**：对偶 vs 差分偏差（57-72%）；π_sell 单调（2/5/10/20% → 164,768/
166,042/168,230/172,761）；碳/峰值 2% infeasible（六区一致）
**数学公式**：`π = ΔCost/ΔRHS`（数值差分）；对偶退化判据：
`marginal ≠ (f(b+δ)−f(b))/δ`（基内梯度 vs 全局斜率）
**证明链**：① 工具发现（scipy linprog highs 实返 marginals——原"不返回"
注释系误判）② 验证门（dual_verify：功率平衡对偶≈电价但差分斜率低 28-45%，
δ∈[1e-4,1] 恒定排除基变换）③ 扩展验证（随机 10/10 小时 57-72% 偏差）④
退化机理（成本面平坦——Q3 E6 跨题印证）
**图**：fig_q4_shadow.png
**口径/边界**：影子价格仅对给定调度成立；不可行档无对偶（如实）；退化
警示（对偶向量在储能问题中不可用——方法学贡献）
**产物映射**：output/q4/q4_shadow.json（dual_verify/degradation）；q4_dual_extended.json
**研究背景**：工具验证门否决解析对偶 → 数值差分为准 → 退化本身成为【实证】
发现（Q3 平坦面→Q4 对偶退化的跨题机理同源）。

### 素材 5-5：任务层碳杠杆上限【实证】

**结论陈述**：任务层碳杠杆双口径：**6 旋钮空间内 0.239%**（mig 扫描实证）/
**构造性绝对上界 ≈1.4%**（AI 全迁 E/F 可行域内扫描，frac=0.7 边界）——
等比例区域碳限额 τ≥1% 即超杠杆能力，**τ∈{10%,20%,30%} 结构性不可达**
（政策级结论：减排需源头或跨区电量调度，非任务调度杠杆）。
**根因链**：AI 占负荷比例小（东区仅 7.4%）→ NonAI 底数稀释 + 调度器迁移
目标=成本最优（非碳最优）+ 区域碳强度差有限（0.42-0.62）。

**支撑数字**：mig∈{0..15} 扫描碳排 1,903,947~1,908,500（±0.12%）；构造扫描
frac=0.6 降 1.16%/frac=0.8 infeasible；τ=0.1 杠杆三族（shift/迁移/联合）全败
**证明链**：① mig 旋钮全档扫描（判别"调度器语义锁死碳杠杆"）② AI 迁 E/F
构造反事实（绝对上界）③ 杠杆三族（A shift24/B 迁移/C 联合）全败 + 归因
（B_migrate 碳排反升——成本驱动调度器）④ 政策级结论（等比例 vs 总量限额）
**产物映射**：output/q4/q4_pressure.json（carbon_lever_floor）；q4_carbon_lever_scan.json
**研究背景**：碳限额场景全 infeasible 的深层归因——不是模型缺陷，是
"任务结构（NonAI 底数）+ 调度器语义"决定的杠杆上限（负结果=证据）。
